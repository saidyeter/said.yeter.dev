This project allows users to create surveys and allows end users to participate surveys. This project contains backend (C#) and frontend (Next.js) separately. 
Backend is an ASP.NET Web API and written in C# with .NET 7. Frontedn is a Next.js app and written with TypeScript.  

Key features :  
- Create survey, manage it, relase it, take it off. 
- Create questions in survey with multi-select options, single select options, free text field answers. 
- Show how many people participated, which questions are answered or skipped with charts reports. 

This app is retired after the survey period, and it will be used on new season.
